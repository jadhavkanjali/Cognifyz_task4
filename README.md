# Cognifyz Internship – Task 4

## API Integration and Front-End Interaction

### About the Project
This project is a simple Student Management System developed as part of the Cognifyz internship. It uses a RESTful API to perform CRUD operations and display student data on a web interface.

### Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- JSON

### Features
- View student records
- Add new students
- Update student details
- Delete student records
- Fetch data using REST API

### How to Run
1. Install Node.js.
2. Open the project folder in VS Code.
3. Run `npm install`.
4. Start the server using `npm start`.
5. Open `http://localhost:3000` in your browser.

### API Endpoints
- `GET /api/students` – View students
- `POST /api/students` – Add a student
- `PUT /api/students/:id` – Update a student
- `DELETE /api/students/:id` – Delete a student

### Learning Outcome
Learned how to create REST APIs, connect the front end with the back end, and perform CRUD operations.
